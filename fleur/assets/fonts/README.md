# Шрифты

Все шрифты распространяются по SIL Open Font License 1.1 (тексты лицензий лежат рядом).

| Роль (`Look.font`) | Файл | Исходник | Что изменено |
| --- | --- | --- | --- |
| `serif`, `serif_bold`, `serif_italic`: весь читаемый текст | `Literata.ttf`, `Literata-Italic.ttf` | Literata (google/fonts, `ofl/literata`, вариативные `[opsz,wght]`) | unitsPerEm 1000 → 1042 (в 0,96 раза мельче, ширина строк как у прежней Georgia); вертикальные метрики 0,93 / 0,27 em вместо очень высоких исходных |
| `display`, `display_bold`, `display_italic`: заголовки, имена, места, меню | `EBGaramond.ttf`, `EBGaramond-Italic.ttf` | EB Garamond (google/fonts, `ofl/ebgaramond`, вариативные `[wght]`) | unitsPerEm 1000 → 870 (крупнее в 1,15 раза, чтобы кегли совпадали с прежней Georgia); вертикальные метрики 0,95 / 0,25 em |
| `hand`: короткие рукописные надписи на карточках | `FleurHand.ttf` | Marck Script (google/fonts, `ofl/marckscript`) | unitsPerEm 1000 → 833 (крупнее в 1,2 раза), метрики 0,95 / 0,30 em. Изменённая версия переименована в «Fleur Hand»: у Marck Script зарезервировано имя шрифта |

Масштаб меняет только размер em: начертания глифов, кернинг и вес не тронуты.

Правило: длинные фразы (реплики, повествование, итоги в листах) набираются прямым `serif`.
Кириллический курсив и рукописный шрифт тяжело читать абзацами. Они годятся для подписей в
одну-две строки.
